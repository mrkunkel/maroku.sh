# Pong App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement a single-player Pong game as a maroku.sh app in `commands/pong.js`, registered in `commands/manifest.json`.

**Architecture:** Single file `commands/pong.js` module following the Tetris app contract (`execute(container, onExit)`). All game logic is client-side JavaScript on a single HTML5 canvas (800×400 px). The game loop uses `requestAnimationFrame`. Layout is centered in the app container with a heading and instructions line.

**Tech Stack:** Vanilla JavaScript, HTML5 Canvas, CSS. Zero external dependencies.

## Global Constraints

- No sound, no music, no visual effects (flashes, particles, transient effects)
- No game-over screen, no win/loss condition, no match timer — endless match
- Ball speed has no upper cap
- Player paddle: 10×80 px, green (#00FF00), x=0, clamped to field
- AI paddle: 10×80 px, red (#FF0000), x=790, clamped to field (decision: changed from unclamped)
- Ball: white (#FFF) circle, 10 px radius, base speed 5 px/frame
- Canvas: 800×400 px, black (#000) background, 4 px white border, soft outer shadow
- Scores: white, 35 px Arial, player at x=200 y=80, AI at x=600 y=80
- Background: dark gray (#222), centered content, no scrollbars
- Heading: "PONG" during play, "PAUSED" when window loses focus
- Instructions below canvas: "Use **Mouse Wheel** to move your paddle" in light gray (#aaa)
- Controls: mouse wheel only, wheel delta × 0.15 px per event, ignored while paused
- Pause: auto-pause on `window.onblur`, auto-resume on `window.onfocus`
- AI: tracks ball y, dead zone ±10 px, constant speed 3.5 px/frame, clamped to field
- Wall bounce: invert vertical velocity with position correction (clamp ball inside walls)
- Paddle collision: AABB overlap; bounce angle = (normalized hit position) × π/4; ball always travels away from hitting paddle
- Speed increase: +0.2 px/frame per paddle hit
- Post-score reset: ball to center, speed to 5, serve toward scoring side, preserve vertical velocity, paddles unchanged
- Cursor hidden over canvas

function draw() {
    // Clear court
    ctx.fillStyle = COLOR_COURT;
    ctx.fillRect(0, 0, COURT_WIDTH, COURT_HEIGHT);

    // Player paddle (left, green)
    ctx.fillStyle = COLOR_PLAYER;

    ctx.fill();

    ctx.fillStyle = COLOR_TEXT;
    ctx.font = '35px Arial';
    ctx.textAlign = 'center';
    ctx.fillText(playerScore.toString(), COURT_WIDTH / 4, COURT_HEIGHT / 5);

    // AI score
    ctx.fillText(aiScore.toString(), COURT_WIDTH * 3 / 4, COURT_HEIGHT / 5);
}

### Task 6: Paddle Collision Detection and Response

**Files:**
- Modify: `commands/pong.js`

**Interfaces:**
- Consumes: `PADDLE_WIDTH`, `PADDLE_HEIGHT`, `BALL_RADIUS`, `BALL_SPEED_INCREMENT` constants, current ball/paddle state
- Produces: AABB collision detection, bounce angle calculation, speed increase, ball always travels away from hitting paddle

- [ ] **Step 1: Add collision detection to update()**

Add this inside `update()`, after the ball movement but before wall bounces:

```javascript
function update() {
    if (isPaused) return;

    // Move ball
    ballX += ballVX;
    ballY += ballVY;

    // Player paddle collision (left side)
    if (ballVX < 0 && ballX - BALL_RADIUS <= PADDLE_WIDTH &&
        ballX + BALL_RADIUS >= 0 &&
        ballY >= playerY && ballY <= playerY + PADDLE_HEIGHT) {
        handlePaddleHit(1, playerY);
    }

    // AI paddle collision (right side)
    if (ballVX > 0 && ballX + BALL_RADIUS >= COURT_WIDTH - PADDLE_WIDTH &&
        ballX - BALL_RADIUS <= COURT_WIDTH &&
        ballY >= aiY && ballY <= aiY + PADDLE_HEIGHT) {
        handlePaddleHit(-1, aiY);
    }

    // Top wall bounce
    if (ballY - BALL_RADIUS <= 0) {
        ballY = BALL_RADIUS;
        ballVY = -ballVY;
    }

    // Bottom wall bounce
    if (ballY + BALL_RADIUS >= COURT_HEIGHT) {
        ballY = COURT_HEIGHT - BALL_RADIUS;
        ballVY = -ballVY;
    }
}

function handlePaddleHit(direction, paddleY) {
    // Normalize hit position: -1 (bottom edge) to +1 (top edge) relative to paddle center
    const relativeY = ((paddleY + PADDLE_HEIGHT / 2) - ballY) / (PADDLE_HEIGHT / 2);
    const clampedY = Math.max(-1, Math.min(1, relativeY));

    // Outgoing angle = clampedY * π/4 (max ±45° from horizontal)
    const angle = clampedY * (Math.PI / 4);

    // Ball always travels away from the paddle that was hit
    // Note: canvas Y axis is flipped, so ballVY uses negative sign
    ballVX = direction * ballSpeed * Math.cos(angle);
    ballVY = -ballSpeed * Math.sin(angle);

    // Increase speed
    ballSpeed += BALL_SPEED_INCREMENT;
}
```

- Top edge hit → ball goes up-right at angle
- Bottom edge hit → ball goes down-right at angle

### Task 8: Scoring and Ball Reset

**Files:**
- Modify: `commands/pong.js`

**Interfaces:**
- Consumes: `COURT_WIDTH`, `BALL_RADIUS`, `BASE_SPEED`, `Math.SQRT2`
- Produces: Score detection (ball crosses left/right edge), score increment, ball reset with serve toward scoring side

- [ ] **Step 1: Add scoring detection and reset to update()**

Add this at the end of `update()`, after AI movement:

```javascript
    // Scoring
    if (ballX + BALL_RADIUS < 0) {
        // Ball crossed left edge — AI scores
        aiScore++;
        resetBall(-1);  // Serve toward left (player) — the winner
    } else if (ballX - BALL_RADIUS > COURT_WIDTH) {
        // Ball crossed right edge — player scores
        playerScore++;
        resetBall(1);  // Serve toward right (AI) — the winner
    }
}

function resetBall(serveDirection) {
    // serveDirection: 1 = serve toward right (player scored), -1 = serve toward left (AI scored)
    ballX = COURT_WIDTH / 2;
    ballY = COURT_HEIGHT / 2;
    ballSpeed = BASE_SPEED;

    // Horizontal direction: toward the side that just scored
    ballVX = serveDirection * BASE_SPEED / Math.SQRT2;

    // Preserve vertical velocity direction from before the score
    const vySign = ballVY >= 0 ? 1 : -1;
    ballVY = vySign * BASE_SPEED / Math.SQRT2;
}
```
