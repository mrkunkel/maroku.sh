This is the beginning of a browser based shell to perform simple tasks for a website admin.

Tasks include:
- `dig <host>` - Look up DNS information for a host
- `ping <host>` - Test network connectivity to a host
- `clear` - Clear the terminal screen (Control+L also works)
- `help` - Show available commands
- `exit` - Close this tab/window

Nothing should be simulated, all commands should actually perform the actions.
